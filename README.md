# Générateur d'Idées Business IA

Un projet [BZHandiBreizh](https://pjbreizh56bzh.github.io/ia-viral-site/) — retrouvez tous nos guides et outils.

Outil gratuit (HTML/CSS/JS vanilla, zéro dépendance) : 4 questions rapides sur votre
secteur, budget, temps disponible et compétence, pour recevoir 3 idées d'entreprise
réalistes tirées d'une base de 14 idées documentées (pitch, premiers pas concrets,
potentiel de revenu réaliste).

Testé de bout en bout (parcours complet du quiz, génération des résultats) avant mise
en ligne.

## Activer GitHub Pages sur ce dépôt

1. **Settings** → **Pages** (menu de gauche).
2. Source : **Deploy from a branch** → branche **main**, dossier **/ (root)**.
3. **Save** — l'outil sera en ligne à
   `https://pjbreizh56bzh.github.io/---orchestrateur-viral---niche-intelligence-pro_files/`.

## Monétisation

Chaque résultat propose un rapport complet personnalisé (10 idées détaillées + plan
d'action 90 jours) à 19€, en achat par virement bancaire : un clic ouvre un e-mail
pré-rempli vers `pjbreizh56bzh@gmail.com` avec le profil du visiteur (secteur, budget,
temps, compétence) et les idées suggérées — de quoi rédiger rapidement le rapport
complet une fois le virement reçu.

## Sur la "viralité"

L'outil est conçu pour être facilement partageable (bouton "copier le lien", résultat
qui donne envie d'essayer). Sa diffusion réelle dépend cependant de vous : partage sur
vos réseaux, dans des groupes d'entrepreneuriat, en description de vos vidéos/contenus
existants (ia-viral-site2, top-outils-ia-2026). Aucun outil ne peut garantir la
viralité — seule la distribution le peut.

## Enrichir la base d'idées

Les 14 idées sont dans [`ideas.js`](ideas.js), chacune taguée par secteur, budget,
temps et compétence pour le moteur de correspondance dans [`app.js`](app.js). Ajoutez-en
en suivant le même format pour diversifier les résultats.
